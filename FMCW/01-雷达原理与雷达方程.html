雷达原理与雷达方程

R⁴ 律、RCS、检测门限与积累增益 —— 一部雷达能看多远，到底由什么决定

一、理论要点

1. 雷达 = 用无线电波"回声测距"

发射电磁波，接收目标反射的回波，从时延、频移、相位差三样东西里解出目标的距离、速度、角度：
τ = 2R / c　（单基地雷达，收发同址）
收发放在一起叫单基地雷达（车载、机载主流）；相距很远叫双基地雷达（抗隐身有奇效，此处不展开）。

2. 三种体制：脉冲 / 连续波 / 调频连续波

脉冲雷达：发短促高功率脉冲，靠回波时延测距 —— 探得远，但近距离有盲区（收发切换期间听不见），需要高峰值功率；
纯连续波（CW）：只能靠多普勒测速，不能测距；
FMCW（调频连续波）：连续发射频率线性爬升的信号，把"距离"编码进"频率" —— 峰值功率低（mW 级即可）、近距盲区小、带宽可做得很大。车载雷达几乎清一色 FMCW。

3. RCS：目标"多能反射"的度量

雷达散射截面积 σ，单位 m²：等效于一个把照射功率全向再辐射的金属球面积。
轿车 10~100 m²｜行人 0.5~1 m²｜自行车 0.5~2 m²
注意 σ 不是几何面积：它与姿态角、频率、材料都有关，还是个统计起伏量（目标一转弯 σ 可能掉一个数量级）。

4. 雷达方程与 R⁴ 律（最重要的一条）

Pr = Pt·G²·λ²·σ / ((4π)³·R⁴)
推导思路四步：发射功率密度 → 目标截获 σ → 全向再辐射 → 接收天线有效口径。R⁴ 的物理原因：去程、回程各衰减一次几何扩散（R²×R²）。
距离 ×2 → 回波弱 16 倍（−12 dB），这就是"看得远"如此昂贵的根源。

5. 检测门限 → 最大探测距离

回波功率必须超过噪声底加所需信噪比：
Pmin = −174 dBm/Hz + 10lg(Bn) + NF + SNRmin
把它代入雷达方程解出 Rmax。快速心算：Pt +3 dB → 距离 ×1.19（2<^(1/4)）；σ 要 ×16 才换来距离 ×2 —— 想靠"加大功率"翻倍探测距离要 +12 dB，即 16 倍功率。

6. 积累增益：白捡的 dB

对 N 个 chirp 做相干积累（2D-FFT 天然完成），信噪比提升：
增益 ≈ 10·lg(N) dB（N=128 → +21 dB）
非相干积累（只加幅度）约只有其一半效果。这就是 FMCW 用一串小功率 chirp 拼出大探测距离的秘密。

7. 77 GHz 频段与法规

车载毫米波雷达的两个窗口：76~77 GHz（长距 LRR）与 77~81 GHz（短距 SRR，4 GHz 带宽）。
λ ≈ 3.9 mm → 天线阵元毫米级，一个芯片塞下多发多收；4 GHz 带宽 → 距离分辨率 3.75 cm。代价：雨衰加大、器件工艺（SiGe/CMOS 毫米波工艺）门槛高。

8. 与激光雷达 / 摄像头一句话对比

毫米波雷达：直接测距测速、全天候（雨雾尘穿透好）、分辨率中等；
激光雷达：几何分辨率极高、易受雨雾干扰、贵；
摄像头：语义信息最丰富（车道线/红绿灯）、不直接测距、怕逆光黑夜。
三者互补，量产方案都是"摄像头 + 毫米波"打底。

二、仿真：雷达方程与最大检测距离

按雷达方程画回波功率随距离的衰减曲线（蓝），与接收灵敏度（黄虚线）比较，交点即最大检测距离（绿虚线）。固定条件：77 GHz（λ=3.9 mm）、Tc=40 µs（每个距离 bin 的噪声带宽 1/Tc=25 kHz）、SNRmin=15 dB。试这三件事：① 切换目标 RCS（轿车→行人），看 Rmax 只缩到 56%；② 拉积累数 N 从 1 到 128，看 +21 dB 换来多少距离；③ 验证距离 ×2 回波 −12 dB（对数横轴下曲线斜率恒定）。
回波功率 Pr(R) 灵敏度门限 Rmax　横轴：距离（对数刻度 1~500 m）

三、小结与常见误区

要点回顾：① 单基地雷达 R = c·τ/2；② 雷达方程 R⁴ 律来自双程扩散，距离×2 → −12 dB；③ Rmax ∝ (Pt·G²·λ²·σ·N)1/4 —— 所有参数都只有"四次根"的杠杆；④ RCS 是统计量不是常数；⑤ 相干积累 +10lgN dB 是最便宜的增益；⑥ 76~77 GHz 走远距、77~81 GHz 用 4 GHz 带宽换分辨率。
误区："发射功率翻倍，探测距离翻倍。"功率翻倍只有 +3 dB，距离只 ×1.19（+19%）。想距离翻倍要 +12 dB（16 倍功率），或想办法吃积累增益、加大天线增益、降低 NF——都比堆功率划算。
误区："RCS = 目标的物理面积。"σ 是等效散射能力，还随姿态角/频率/极化剧烈起伏。一辆车正对与侧对雷达的 σ 能差一个数量级；行人实测值在 0.5~1 m² 附近摆动，所以雷达方程算出的 Rmax 是统计意义上的。
误区："雷达方程给出一个精确的探测距离。"实际检测是概率事件：给定虚警率 Pfa，检测概率 Pd 随 SNR 平滑上升（还有 Swerling 起伏模型），Rmax 只是"Pd=90%"这类门限的另一种说法，边界是"软"的。
