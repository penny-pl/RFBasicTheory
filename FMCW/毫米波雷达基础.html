毫米波雷达基础（FMCW）

线性调频 Chirp · 拍频测距 · 多普勒测速 · 距离-多普勒二维处理 —— 全部仿真在浏览器本地运行

一、雷达基础理论

1. 雷达方程（最重要的一条）

接收功率与距离的四次方成反比：
Pr = Pt·G²·λ²·σ / ((4π)³·R⁴)
距离翻倍，回波弱 16 倍（−12dB）！这就是雷达"看得远"如此困难的根本原因。仿真④可亲手验证。

2. 目标散射截面积 RCS（σ）

衡量目标"反射雷达波的能力"，单位 m²。典型值：轿车 ≈ 10 m²，行人 ≈ 1 m²，自行车 ≈ 2 m²，隐形飞机可低于 0.001 m²。σ 越小越难发现。

3. 为什么车载雷达选 77 GHz？

波长约 3.9 mm → 天线仅毫米级，可把多个收发通道集成进指甲盖大的芯片；法规允许 76~81 GHz 共 5 GHz 带宽 → 距离分辨率达厘米级。代价：路径损耗大、器件工艺要求高。

4. 完整信号处理链

回波 → 混频得中频 → ADC 采样 → 距离 FFT（快时间）→ 多普勒 FFT（慢时间，跨 chirp）→ CFAR 检测 → 角度 FFT（跨天线）→ 点云与跟踪。本页仿真③演示的就是前三步。

5. CFAR 恒虚警检测

噪声起伏不定，固定门限会忽漏忽虚。CFAR 用每个单元周围邻域的平均噪声自适应设门限，保证虚警率恒定（如 10⁻⁶）。是雷达从"频谱图"变成"目标列表"的关键一步。

6. 角度测量与 MIMO 阵列

同一回波到达相邻接收天线的相位差 Δφ = 2π·d·sinθ/λ，据此求到达角 θ。多发多收（MIMO）可虚拟出几十上百个阵元，角分辨率 Δθ ≈ λ/(N·d) —— 毫米波雷达因此能"成像"。

二、FMCW 核心公式速览

1. 什么是毫米波雷达？

工作在 76~81 GHz（车载）、60 GHz（室内）等频段，波长仅约 4 mm。波长短 → 天线可以做得很小，分辨率极高，广泛用于汽车辅助驾驶、手势识别、生命体征监测。

2. FMCW 与 Chirp

FMCW（调频连续波）发射频率随时间线性爬升的信号，称为一个 chirp：
f(t) = f₀ + (B/Tc)·t
B = 扫频带宽，Tc = chirp 周期，斜率 S = B/Tc。

3. 拍频测距（核心！）

回波比发射信号晚 τ = 2R/c。发射与接收混频后得到恒定差频（拍频/中频）：
fb = S·τ = 2·S·R / c
R = c·fb / (2S)
测频率 → 得距离，这就是 FFT 登场的地方。

4. 距离分辨率

两个目标要能分开，拍频至少差一个 FFT 谱线（1/Tc），推导出：
ΔR = c / (2B)
只取决于带宽 B！B=1 GHz → ΔR=15 cm；B=4 GHz → ΔR≈3.75 cm。

5. 多普勒测速

运动目标使回波相位逐 chirp 变化。连发 N 个 chirp，对每个距离单元沿"慢时间"再做一次 FFT（二维 FFT）：
v = λ·fd / 2，Δv = λ / (2·N·Tc)
最大不模糊速度 vmax = λ/(4Tc)。

6. 最大不模糊距离

拍频不能超过 ADC 采样率的一半：
Rmax = fs·c / (4S)
工程上还要考虑 CFAR 恒虚警检测、角度估计（多天线阵列）等，构成完整信号处理链。

三、仿真 ①：Chirp 时频图与拍频的产生

发射 chirp（蓝）经目标反射后延迟 τ 返回（粉），混频得到恒定差频——拍频（绿）。目标越远，延迟越大，拍频越高。
发射 fTX(t) 接收 fRX(t)（延迟 τ=2R/c）
拍频 fb(t) = fTX − fRX（在有效区为常数）

四、仿真 ②：拍频信号 → FFT → 测距

按 ADC 采样率对拍频信号采样 256 点并做 FFT。谱峰位置换算出距离。可开第二个目标，观察两个目标距离太近时谱峰无法区分——这就是 ΔR=c/2B 的物理意义（默认 B 下 ΔR=15 cm，两目标需差 15 cm 以上）。

五、仿真 ③：距离-多普勒二维图（2D-FFT）

连续发射 64 个 chirp，每个采 128 点：先沿快时间做 FFT 得距离维，再沿慢时间做 FFT 得速度维，得到距离-多普勒热力图（RD Map）。亮斑即目标——这是车载雷达"看到"世界的原始画面。
横轴：多普勒速度（m/s，负=远离）｜纵轴：距离（m）｜颜色越亮回波越强（dB）

六、仿真 ④：雷达方程 —— 回波功率与检测距离

按雷达方程计算不同距离下的回波功率（蓝线），与接收机灵敏度（黄线）比较，交点即最大检测距离。调发射功率、天线增益、目标 RCS 观察检测距离变化。注意纵轴是对数刻度：距离 ×2，回波 −12 dB。

七、CFAR 检测与角度估计理论

1. 从"频谱图"到"目标列表"：为什么需要 CFAR

做完 2D-FFT 得到的只是热力图，雷达输出给整车的必须是一份干净的目标清单。直接设固定门限的问题：噪声功率随距离、温度、干扰起伏——门限高了漏警、低了满屏虚警。CFAR（恒虚警率检测）让门限跟着局部噪声走，把虚警率钉死在设定值（如 10⁻⁶，即百万个单元最多 1 次误报）。

2. CA-CFAR（单元平均）原理

对每个待测单元（CUT），取两侧各若干个训练单元的平均功率估计本地噪声，中间留保护单元防止目标能量泄漏进估计：
门限 T = α × 训练单元均值
α = N·(Pfa−1/N − 1)（N=训练单元数）

3. CFAR 家族

CA（均值）：均匀噪声里最优，但多目标互相遮蔽；GO（取大）：抗遮蔽；SO（取小）：杂波边缘不虚警；OS（有序统计）：取排序后第 k 个，综合性能最好，车载雷达常用 OS-CFAR。

4. 角度估计原理

平面波到达间距 d 的相邻天线，波程差 d·sinθ 产生相位差：
Δφ = 2π·d·sinθ / λ
对各天线接收的复信号做空间 FFT（也叫数字波束形成 DBF），谱峰位置即 sinθ。仿真⑥可验证。

5. 角分辨率与孔径

Δθ ≈ λ / (M·d)（弧度）
M 个天线、半波长间距：4 通道约 28°，16 通道约 7°。所以车载雷达用 MIMO 虚拟阵列（如 3 发 4 收虚拟出 12 通道）扩大孔径。

6. 完整处理链总结

ADC 数据 → 距离 FFT → 多普勒 FFT → CFAR 检测（拿到目标点）→ 对每个检测点做角度 FFT（拿到方位）→ 聚类/跟踪（Kalman）→ 输出目标列表：距离、速度、角度、强度。

八、仿真 ⑤：CA-CFAR 恒虚警检测

一条含噪距离谱（有两个目标 + 一片杂波区抬高噪声底）。粉色曲线是 CA-CFAR 自适应门限——杂波区门限自动抬高，保持虚警率恒定。绿圈=检出的目标。对比试试：调训练单元数 N 或 Pfa，观察门限平滑度与高度的变化。

九、仿真 ⑥：阵列角度估计（空间 FFT）
