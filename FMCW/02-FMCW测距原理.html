FMCW 测距原理

chirp · 拍频 · 距离分辨率只看带宽 —— 把"测距问题"变成"测频问题"

一、理论要点

1. 为什么要"调频"

纯连续波只能测多普勒速度，无法测距（回波永远在听）。让发射频率随时间线性爬升，回波的延迟就变成了频率差——这就是 FMCW（调频连续波）。
相比脉冲雷达：近距盲区小（不需要收发切换）、峰值功率 mW 级（易过法规、易集成）、瞬时带宽可做吉赫兹（分辨率高）。

2. chirp 与斜率 S

一段频率线性爬升的信号叫一个 chirp：
f(t) = f₀ + S·t，　S = B / Tc
B = 扫频带宽，Tc = chirp 时长，S = 斜率（MHz/µs）。77 GHz 雷达典型的 S 是每微秒几到几十 MHz。

3. 拍频：发射减接收（核心！）

目标在 R 处，回波延迟 τ = 2R/c。发射与回波混频（相乘取差频），得到恒定的拍频（中频）：
fb = S·τ = 2·S·R / c　⇔　R = c·fb / (2S)
单个静止点目标的中频信号就是一根纯净的单频正弦——测距离 = 测频率，FFT 由此登场。

4. range-FFT：谱峰位置即距离

对一个 chirp 内采样的中频信号做 FFT：
峰在第 k 个 bin → fb = k·fs/N → R = c·k·fs/(2S·N)
多个目标 = 多根谱线，谱峰高度按各自的回波强度（∝ σ/R⁴）排序。这就是"快时间维"处理。

5. 距离分辨率 ΔR = c/2B，只看带宽

两个目标能分开，拍频差必须超过一条谱线宽度（1/Tc）：
Δfb = S·2ΔR/c ≥ 1/Tc ⇒ ΔR ≥ c/(2·S·Tc) = c/2B
B=1 GHz → 15 cm；B=4 GHz → 3.75 cm。与斜率、采样率、FFT 点数都无关——想要更细的距离格，只有加带宽。

6. 最大不模糊距离 Rmax = fs·c/(4S)

拍频不能超过 ADC 采样率的一半（fb ≤ fs/2）：
Rmax = fs·c / (4S)
斜率 S 是把双刃剑：斜率大 → 同样距离拍频高、谱线分得开，但 Rmax 被压缩。想远又要快，见《chirp 参数设计》。

7. 多目标谱的形状

理想点目标是一根谱线；实际谱峰会被加窗展宽（Hann 窗主瓣宽、旁瓣低）；目标有径向尺寸（如卡车侧面）时谱峰本身就宽。谱峰高度 ≈ 回波功率，遵守 R⁴ 律。

8. 进阶：chirp 线性度

上面一切的前提是"频率严格线性爬升"。若斜率有起伏，残余相位误差会使谱峰展宽、抬底，分辨率恶化。工程上用闭环 PLL（锁相环）+ 高稳定本振保证线性度——这是毫米波芯片的核心指标之一。

二、仿真 ①：chirp 时频图与拍频的产生

发射 chirp（蓝）经目标反射延迟 τ 返回（粉），两者相减得到恒定拍频（绿）。目标越远 → 延迟越大 → 拍频越高，这就是"距离编码进频率"。注意绿色只在 t > τ 的有效区内存在（chirp 尾巴上发射与接收已不在同一周期，工程上靠丢弃尾部或留 idle 时间处理）。
发射 fTX(t) 接收 fRX(t)（延迟 τ=2R/c）
拍频 fb(t) = fTX − fRX（有效区内为常数）

三、仿真 ②：拍频信号 → FFT → 测距

固定斜率 S = 10 MHz/µs、采样率 fs = 10 MHz（Rmax = 75 m）。调节带宽 B（斜率不变，Tc=B/S 随之变长）并做 256~4096 点 FFT。试试：① 把 B 调小到 250 MHz（ΔR=0.6 m），再把目标 2 拉近到与目标 1 相距 < 0.6 m —— 两峰合并成一个；② 加噪声看谱峰仍稳（FFT 积累增益）；③ 核对读数：ΔR = c/2B 只随 B 变。

四、小结与常见误区

要点回顾：① 回波延迟 τ=2R/c，混频得拍频 fb=2SR/c；② 单静止点目标的中频信号是单频正弦，range-FFT 谱峰位置即距离；③ ΔR=c/2B 只由带宽决定；④ Rmax=fs·c/(4S) 由斜率与采样率决定；⑤ 斜率线性度决定谱峰干不干净；⑥ 一切前提：先有良好的 chirp，才有干净的谱。
误区："分辨率不够就加 FFT 点数 / 提高采样率。"补零和加密采样只是把谱线画密（插值），两个目标的拍频差若小于 1/Tc 对应的 c/2B，峰永远糊在一起。唯一出路是加大带宽 B。
误区："斜率越大越好——谱线分得更开。"斜率大确实让远处目标的拍频更高、谱上离得远，但拍频上限是 fs/2：S 翻倍，Rmax 直接减半。S、fs、B、Tc 是一组联动约束（见《chirp 参数设计》）。
误区："ΔR=15 cm 说明测距精度只有 15 cm。"分辨率≠精度。分辨率是"分开两个目标"的最小间距；单目标的测距精度可以远优于 ΔR（对谱峰做内插，高 SNR 下可达毫米级）——就像刻度 1 mm 的尺子能估读到 0.1 mm。
