卷积与 LTI 系统

滤波的时域本质 —— 翻转、平移、相乘、求和，输出一个点一个点"长"出来

一、理论要点

1. LTI 系统：被一个序列完全决定

同时满足线性（叠加成立）与时不变（今天测和明天测一样）的系统叫 LTI。给 LTI 输入一个单位脉冲 δ[n]，输出 h[n]（脉冲响应）——知道 h[n]，系统就完全确定了，任何输入的响应都能算出来。

2. 卷积：LTI 的万能公式

y[n] = (x ∗ h)[n] = Σₖ h[k]·x[n−k]
口诀：翻转 → 平移 → 相乘 → 求和。把 h 反过来，滑到位置 n，与 x 对应相乘再求和，得到 y 的一个点；滑过全程就得到整条输出。卷积满足交换律，长度 = 两序列长度之和 −1。

3. FIR 滤波器 = 卷积本身

FIR（有限脉冲响应）滤波器的差分方程：
y[n] = b₀x[n] + b₁x[n−1] + … + bMx[n−M]
系数 bₖ 就是脉冲响应 h[k]。滤波器设计（窗函数法等）本质上就是"挑一组好的卷积系数"。

4. 时域卷积 = 频域相乘

Y(f) = H(f) · X(f)
卷积很慢（N×M 次乘法），相乘很快——先用 FFT 把两个信号变到频域，相乘，再 IFFT 回来（快速卷积），长序列时快几个数量级。OFDM、雷达信号处理的实时性都靠它。

5. 频率响应：h 的"另一面"

H(f) 就是 h[n] 的傅里叶变换。|H(f)| 告诉你每个频率被放大或压低多少，∠H(f) 告诉你被延迟多少相位。例：M 点滑动平均，|H| 是低通（高频抵消），截止约 0.44·fs/M。

6. 为什么正弦是"特征函数"

正弦进 LTI，输出还是同频正弦，只改幅度和相位——因为 e^(jωt) 卷积上任何 h 都只乘一个 H(ω)。这就是频域分析法的根基（见《傅里叶级数与频谱》）。

7. 群时延：滤波的代价

因果滤波器（只用过去数据）必然引入延迟。M 点滑动平均的延迟 = (M−1)/2 个样本；FIR 的"线性相位"意味着所有频率延迟同样时间，波形形状不变，只是整体平移。

8. 工程直觉：到处都是卷积

回声 = 信号与 {1, 0, 0, …, 0.6} 卷积；多径信道 = 与一串 δ 卷积；图像模糊 = 二维卷积；天线方向图 = 口径场分布的傅里叶变换（本质同源）。看到"输出是输入的加权滑动叠加"，就往卷积想。

二、仿真 ①：滑动卷积 —— 输出一个点一个点"长"出来

上：输入 x[n]（杆图）；中：翻转后的 h 滑到当前位置 n（参与相乘的样本高亮）；下：输出 y[n] 已算出的部分。拖动位置 n（或播放），看每个输出点如何由"对齐样本相乘求和"得到。选"回声"卷积核，观察输出里出现延迟的复制品。

三、仿真 ②：方波过低通 —— 卷积的眼睛可见版

四、小结与常见误区

要点回顾：① LTI 由 h[n] 完全刻画，输出=卷积；② 口诀：翻转-平移-相乘-求和；③ FIR 系数即 h[k]；④ 时域卷积=频域相乘，FFT 加速；⑤ |H| 定增益、∠H 定延迟，线性相位=统一延迟；⑥ 滑动平均是最简单的低通，代价是延迟与钝化。
误区："卷积只是数学运算，跟滤波没关系"。滤波就是卷积。你调的每一个 FIR/IIR 滤波器、每一个"滑动平均平滑"，背后都是同一件事。反过来，测量系统脉冲响应的标准方法（打脉冲看输出）依据也是它。
误区："滤波后信号立刻变干净"。滤波必有延迟与暂态：FIR 前 M−1 点处在"数据不满"的边缘，输出不完全可信；陡峭的滤波还会带来振铃（吉布斯）。实时系统里"马上要用输出"时要考虑这段延迟。
误区："滑动平均点数越多越好"。M 越大越平滑，但延迟 (M−1)/2 也越大、通带损耗越多，且第一个零点后还有泄漏瓣。真正像样的滤波器要用精心设计的系数（汉宁窗法、等波纹法），而不是无限加长平均。
延伸阅读：《傅里叶级数与频谱》——方波谐波结构与吉布斯现象；《FFT 频谱分析》——|H| 如何测出；《滤波器频响》——模拟滤波器家族。
