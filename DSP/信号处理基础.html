信号处理基础（DSP）

采样定理 · 混叠 · 量化 · FFT 频谱分析 · 窗函数与频谱泄漏 —— 全部仿真在浏览器本地运行，可离线使用

一、信号、噪声与傅里叶思想

1. 信号的三要素

最基本的信号是正弦波，由三个参数完全确定：
x(t) = A·sin(2π·f·t + φ)
A 幅度（强弱）、f 频率（快慢）、φ 相位（起点）。任何复杂信号都可以拆解成一堆这样的正弦波。

2. 时域与频域：同一信号的两种看法

示波器看时域：电压随时间怎么变；频谱仪看频域：信号由哪些频率组成、各多强。两者携带完全相同的信息，傅里叶变换就是这两个视角之间的"翻译器"。

3. 傅里叶的核心思想

任何周期信号 = 基波 + 一系列谐波正弦的叠加（傅里叶级数）：
方波 = (4/π)·[sin(ωt) + sin(3ωt)/3 + sin(5ωt)/5 + …]
非周期信号则用连续的频率成分叠加（傅里叶积分）。下面仿真①可亲手验证。

4. 噪声：无处不在的干扰

白噪声：所有频率功率相同（像白光）；高斯噪声：幅度服从正态分布。两者常同时成立（AWGN）。电阻热噪声功率：
N = k·T·B（−174 dBm/Hz @ 290K）
带宽越宽，收进来的噪声越多。

5. 信噪比 SNR 与噪声系数

SNR(dB) = 10·lg(P信号/P噪声)
SNR 决定能否可靠检测/解调。器件会恶化 SNR，恶化量叫噪声系数 NF：理想器件 NF=0dB，优秀 LNA 约 1~2dB。

6. 如何读懂一幅 FFT 频谱

N 点实信号做 FFT 得 N 个复数 X[k]，第 k 条谱线对应频率 fk = k·fs/N |X[k]| 是该频率的幅度，∠X[k] 是相位。实信号的频谱左右对称（共轭对称），所以只看前半边。信号频率不在谱线上时能量"泄漏"到邻近谱线（栅栏效应）。

二、仿真 ①：傅里叶级数合成 —— 信号是"拼"出来的

用有限个正弦谐波叠加逼近方波/锯齿波。从 1 个谐波开始逐个增加，看波形如何一步步"长"成目标形状——FFT 做的事情正是反过来：把给定波形拆成这些谐波的幅度和相位。方波在跳变处始终有约 9% 的过冲（吉布斯现象），这就是"有限带宽"的代价。

三、采样、量化与频谱分析理论

1. 采样定理（奈奎斯特）

要从采样值中无失真恢复原信号，采样率必须大于信号最高频率的 2 倍：
fs > 2 · fmax
这个临界值 fs/2 称为奈奎斯特频率。实际工程一般留余量，取 2.5~5 倍。

2. 混叠（Aliasing）

采样率不足时，高频信号会"伪装"成低频信号，且无法事后区分。混叠后的表观频率：
falias = |f − n·fs|（折回到 0 ~ fs/2 内）
对策：采样前加抗混叠低通滤波器。

3. 量化与 ADC 位数

ADC 把连续幅度离散化为 2N 个等级，引入量化噪声。理想 N 位 ADC 的信噪比：
SNR ≈ 6.02·N + 1.76 (dB)
12 位 ≈ 74 dB，16 位 ≈ 98 dB。

4. DFT 与 FFT

离散傅里叶变换把 N 点时域信号变成 N 点频域谱：
X[k] = Σ x[n]·e−j2πkn/N
直接算要 N² 次乘法，FFT 用分治法降到 N·log₂N：1024 点从约 100 万次降到约 1 万次。

5. 频率分辨率

N 点采样、采样率 fs 时，频谱相邻两点间隔：
Δf = fs / N
想看清两个靠近的频率，就要采更长的时间（而不是更高的采样率）。

6. 频谱泄漏与窗函数

信号频率不在 FFT 谱线上（非整周期截断）时，能量会"漏"到邻近谱线。加窗（汉宁、汉明等）压窄泄漏，代价是主瓣变宽：
矩形窗：分辨率高、泄漏大；汉宁窗：折中
