二、推荐学习路线

三条路线按目标取舍;每条都从零基础起步,DSP 类是公共底座。

📡 路线 A · 射频硬件链路(9 页)

目标:看得懂射频链路框图与指标手册。dB → 传输线 → 匹配 → 滤波器 → 噪声 → 非线性 → PLL。

🚗 路线 B · 毫米波雷达(12 页)

目标:吃透 77GHz 车载雷达从 chirp 到点云的完整处理链。DSP 打底 → 雷达方程 → 测距测速 → 参数设计 → CFAR → 测角 → 全流水线。

📻 路线 C · SDR 软件无线电(13 页)

目标:拿起 RTL-SDR/Pluto 就知道信号在链路里发生了什么。DSP 全览 → 架构 → 采样 → DDC → 调制 → 信道 → 频谱仪。
