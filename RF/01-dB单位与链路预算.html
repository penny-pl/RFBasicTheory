dB 单位与链路预算

把乘法世界变成加法世界 —— 从 dB/dBm 换算到自由空间链路预算

一、理论要点

1. dB：比值取对数

射频世界里功率动辄相差 1012 倍（发射 kW、接收 pW），用对数把乘除变加减：
功率比：10·lg(P₂/P₁)　幅度比：20·lg(V₂/V₁)
dB 不是单位，只是比值。口诀：+3 dB ≈ ×2（实为 1.995），+10 dB = ×10，−3 dB = 一半功率。

2. dBm / dBW / dBc：给 dB 一个"零点"

P(dBm) = 10·lg(P / 1 mW)
0 dBm = 1 mW，30 dBm = 1 W，−30 dBm = 1 µW。dBW 比 dBm 小 30：dBW = dBm − 30。dBc 是相对载波的 dB（杂散、交调、相位噪声都用它）。

3. 50Ω 系统里 dBm ↔ 电压

P = V²rms/R　→　Vrms = √(P·R)
0 dBm@50Ω → 223.6 mVrms；30 dBm（1 W）→ 7.07 Vrms，峰峰值 Vpp = 2√2·Vrms ≈ 20 V。注意换算依赖阻抗假设（频谱仪 50Ω、视频 75Ω）。

4. 天线增益与 EIRP

dBi 相对各向同性天线，dBd 相对半波偶极子：dBi = dBd + 2.15。天线是无源器件，"增益"来自把能量集中到某个方向。等效全向辐射功率：
EIRP = Ptx + Gtx (dBm)

5. 自由空间路径损耗 FSPL

FSPL = 20·lg(4πR/λ) = 32.44 + 20·lg(f/MHz) + 20·lg(R/km)
例：5.8 GHz、10 km → 32.44 + 75.3 + 20 = 127.7 dB。它假设收发都是全向天线，本质是能量球面扩散；距离每翻倍 +6 dB，频率每翻倍 +6 dB。

6. Friis 传输方程：链路预算

Prx = Ptx + Gtx + Grx − FSPL　(dBm)
全部变成一串加减：30 + 20 + 20 − 127.7 = −57.7 dBm。这就是"链路预算"——预算表里每一项都是一个 dB 数，正负相抵得到接收功率。

7. 链路余量（fade margin）

余量 = Prx − Pmin（接收机灵敏度）
自由空间是理想情况：多径衰落可深达 20~30 dB，雨衰（>10 GHz 明显）、人体遮挡 3~10 dB、极化失配与接头损耗 1~3 dB 都要吃余量。工程上至少留 10~20 dB。

8. 一张预算表走完全程

发射功率 30 dBm → +发射天线 20 dBi → EIRP 50 dBm → −FSPL 127.7 dB → −77.7 dBm → +接收天线 20 dBi → Prx = −57.7 dBm → 若灵敏度 −90 dBm → 余量 +32.3 dB ✓。下面仿真②用的正是这组默认参数，可逐项核对。

四、小结与常见误区

要点回顾：① dB 是比值（功率 10lg、幅度 20lg），+3dB≈×2、+10dB=×10；② dBm 以 1mW 为零点，dBW=dBm−30；③ 50Ω 下 0dBm=223.6mVrms；④ EIRP=Ptx+Gtx；⑤ FSPL=20lg(4πR/λ)，距离/频率每翻倍 +6dB；⑥ Prx=Ptx+Gtx+Grx−FSPL；⑦ 余量=Prx−Pmin，至少留 10~20dB。
误区："dB 和 dBm 都是 dB，随便加"。dB 是比值、dBm 是绝对电平：dBm ± dB = dBm（加减增益/损耗），但 dBm + dBm 没有意义（那是把两个功率相乘）。同样 dBµV、dBc 各有各的零点，混算必错。
误区："FSPL 随频率升高而增大，所以频率越低越好"。FSPL 默认收发都是全向天线。若固定的是天线口径（雷达、卫星、点对点微波），天线增益 G∝f²，口径相同时高频链路反而占优——这正是雷达和卫星往毫米波走的原因之一。
误区："链路余量算出来是正的就能通"。自由空间模型没有多径、遮挡、雨衰、极化失配。城市里多径衰落深度可达 20~30dB；只留 2~3dB 余量的链路，一阵雨、一个人走过天线前就可能断。
