射频基础（RF）

dB 与功率换算 · LC 滤波器频响 · 阻抗匹配与反射 —— 全部仿真在浏览器本地运行，可离线使用

一、电磁频谱与射频链路基础

1. 电磁频谱划分与传播特性

HF(3~30MHz) 电离层反射，短波电台通全球；VHF/UHF(30M~3G) 视距传播，FM 广播、手机、WiFi；微波(3G~300G) 直线传播、雨衰明显，雷达与卫星。频率越高 → 带宽越大、天线越小，但绕射和穿透能力越差。

2. 为什么高频电路"不一样"

低频时导线只是连线；当线长接近波长的 1/10，电压电流沿线呈波动分布，必须按传输线处理。高频电流还只走导体表面（趋肤效应）：
δ = √(2ρ/ωμ)，铜在 1GHz 时 δ≈2µm
这就是射频走线要控阻抗、镀银、尽量短的原因。

3. 传输线与特征阻抗

均匀传输线用分布电感电容描述，特征阻抗：
Z₀ = √(L′/C′)
与线长无关。50Ω 是功率容量与损耗折中的行业标准（75Ω 用于视频）。微带线、同轴线、波导都是它的物理实现。

4. 接收灵敏度

接收机能听到的最弱信号：
Pmin = −174 dBm/Hz + 10·lgB + NF + SNRreq
例：B=10kHz、NF=5dB、需 SNR=10dB → −124 dBm。带宽越窄越"灵敏"，这就是对讲机窄带的原因之一。

5. 非线性：P1dB 与 IP3

放大器输入过大时增益被压缩：P1dB = 增益掉 1dB 的输出功率点。双音信号还会产生三阶交调（2f₁−f₂ 等，落在带内滤不掉），用 IP3 衡量。仿真③可直观看到。

6. 相位噪声

理想本振是一根谱线，实际本振频率随机抖动，谱线两侧有"裙边"——相位噪声，单位 dBc/Hz@偏移。它限制接收机抗强邻道干扰能力，也直接决定雷达的速度测量精度。

二、关键概念与公式

1. 为什么用 dB？

射频链路中信号功率动辄相差 10¹⁰ 倍（发射 kW、接收 pW），用对数刻度 dB 把乘法变加法：
功率：P(dBm) = 10·lg(P/1mW)
电压：20·lg(V₂/V₁)；功率：10·lg(P₂/P₁)
口诀：+3dB ≈ ×2，+10dB = ×10，−3dB = 一半。

2. 频率与波长

λ = c / f　(c ≈ 3×10⁸ m/s)
1 GHz → λ = 30 cm；77 GHz 毫米波雷达 → λ ≈ 3.9 mm。波长短到与电路尺寸相当时，导线就要当传输线处理。

3. 滤波器

按功能分：低通 / 高通 / 带通 / 带阻。关键指标：截止频率 fc（−3dB 点）、阶数 N（越高滚降越陡，每阶约 −20dB/十倍频程）、带内纹波、群时延。巴特沃斯型：通带最平坦。

4. 阻抗匹配与反射

信号沿线传播遇到阻抗突变会产生反射。反射系数：
Γ = (ZL − Z₀)/(ZL + Z₀)
ZL = Z₀（通常 50Ω）时 Γ=0，能量全部传给负载——这就是匹配。

5. VSWR 与回波损耗

VSWR = (1+|Γ|)/(1−|Γ|)
RL = −20·lg|Γ| (dB)
VSWR=1 完美匹配；VSWR=2 意味着约 11% 功率被反射（RL ≈ 9.5dB）。

6. S 参数

高频下电压电流难直接测量，改用入射/反射波描述网络：S₁₁ = 输入反射（回波损耗），S₂₁ = 正向传输（增益/插损）。矢量网络分析仪（VNA）就是测它的。

七、锁相环（PLL）与环路滤波器理论

1. PLL 是什么：一个相位反馈系统

锁相环让 VCO 的输出相位死死盯住参考晶振的相位，从而得到"晶振级稳定度"的任意频率。四个部件构成闭环：
参考晶振fref，如 10 MHz
→
鉴相器 PD比较相位差
→
环路滤波器 LF决定动态性能
→
VCO电压→频率
→ 输出
←—————— ÷N 分频器（反馈支路）←——————
相位差 → 误差电压 → 修正 VCO 频率 → 相位差缩小……直到锁定（相位差恒定、频率精确相等）。

2. 鉴相器（PD）

把两个信号的相位差转换为误差信号。模拟乘法器、异或门、以及频率合成器标配的鉴频鉴相器 PFD（带电荷泵，还能在失锁时指示频率方向，帮助捕获）。

3. 环路滤波器：PLL 的"大脑"

一阶环无滤波器（只有增益），必留静态相位误差。主流是比例+积分（PI）二阶环：
F(s) = Kp + Ki/s
积分支路让频率误差被"记住"并消除（锁定后相位误差为零），比例支路提供阻尼。

4. 阻尼系数 ζ 与环路带宽 ωn

二阶环的阶跃响应完全由这两个参数决定：
ωn = √(Ki/N)，ζ = Kp·N/(2ωn·N)·…（工程上直接调 Kp、Ki）
ζ<1 欠阻尼：快但过冲振铃；ζ≈0.7 常用折中；ζ>1 过阻尼：稳但慢。仿真⑤直接演示。

5. 环路带宽的权衡

环路带宽以内：跟踪晶振的相位噪声（×20·lgN 恶化）；带宽以外：保留 VCO 自身噪声。带宽窄→滤掉参考杂散好，但锁定慢、抑制不了 VCO 近端噪声；带宽宽→锁定快，但杂散和参考噪声容易混进来。

6. 频率合成应用

fout = N × fref
改变分频比 N 即改变输出频率——MCU 时钟、WiFi/5G 本振、雷达 chirp 源都靠它。整数 N 步进 = fref；要更小步进就用小数 N 分频（Σ-Δ 调制抖动 N 值），代价是量化杂散。

八、仿真 ⑤：PLL 锁定过程瞬态仿真

对"PD(增益1) → PI 环路滤波器 → VCO(增益1) → ÷N"的二阶环做逐点数值仿真。VCO 自由振荡频率故意偏开 1%，观察闭环如何把它拉入锁定。调阻尼 ζ 看欠阻尼振铃与过阻尼迟缓；调环路带宽看锁定速度。这正是环路滤波器设计的核心画面。
