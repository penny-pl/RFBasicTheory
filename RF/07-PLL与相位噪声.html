PLL 与相位噪声

锁相、环路带宽的权衡、dBc/Hz 的裙边 —— 频率合成的两大命门

一、理论要点

1. PLL 是什么：一个相位反馈系统

锁相环让 VCO 的输出相位死死盯住参考晶振的相位，从而得到"晶振级稳定度的任意频率"。四个部件构成闭环：
参考晶振fref，如 10 MHz
→
鉴相器 PD比较相位差
→
环路滤波器 LF决定动态性能
→
VCO电压→频率
→ 输出
←—————— ÷N 分频器（反馈支路）←——————
相位差 → 误差电压 → 修正 VCO 频率 → 相位差缩小……直到锁定（相位差恒定、频率精确相等）。

2. 鉴相器（PFD + 电荷泵）

把两个信号的相位差转换为误差信号。频率合成器标配鉴频鉴相器 PFD：带电荷泵，失锁时还能指示频率偏移方向帮助捕获，锁定后相位误差可压到零附近。

3. 环路滤波器：PLL 的"大脑"

一阶环必留静态相位误差，主流是比例+积分（PI）二阶环：
F(s) = Kp + Ki/s
积分支路"记住"并消除频率误差（锁定后相位误差→0），比例支路提供阻尼。

4. 阻尼 ζ 与环路带宽 ωn

二阶环的动态完全由这两个参数决定：ζ<1 欠阻尼（快但振铃），ζ≈0.7 常用折中，ζ>1 过阻尼（稳但慢）。锁定时间量级：
tlock ≈ 4/(ζ·ωn)
仿真①直接演示这三种形态。

5. 环路带宽的两难

带宽以内：输出跟随参考噪声（恶化 20·lgN）；带宽以外：只剩 VCO 自身噪声。带宽窄→杂散抑制好、锁定慢、压不住 VCO 近端噪声；带宽宽→锁定快、但参考噪声与杂散混进来。最优带宽通常取两条噪声曲线交点附近——仿真②看得很清楚。

6. 整数 N 与小数 N 分频

fout = N × fref
整数 N 的频率步进被 fref 锁死（要小步进就得降 fref，环路带宽跟着受累）。小数 N用 Σ-Δ 调制快速抖动 N 值实现分数倍分频，步进任意小，代价是量化杂散（需更强的环路滤波/补偿）。

7. 相位噪声：理想谱线并不存在

理想本振是一根无限细的谱线，实际本振相位随机抖动，谱线两侧出现"裙边"——相位噪声 L(f)，单位 dBc/Hz（偏离载频 f 处 1Hz 带宽内的功率 / 载波功率）。它决定：发射 EVM、接收机抗强邻道（倒易混频）、雷达测速精度、高采样率 ADC 的时钟抖动。

8. 裙边的形状

典型曲线分段：近端 1/f³ 闪烁区（−30 dB/dec）→ 中段 −20 dB/dec 环路区 → 远端平坦噪底。闭环 PLL 在带宽内呈现"参考×20lgN 的平台"，带宽外跟随 VCO。整体 = 两条曲线按环路传递函数加权取优——PLL 自动选择两个噪声源中较好的那个。

9. 积分相噪 → RMS 抖动

σφ = √(2∫L(f)df) rad，tjitter = σφ/2πf₀
把 dBc/Hz 曲线在指定频段（如 12 kHz~20 MHz）积分，得到 RMS 相位抖动（rad），再除以 2πf₀ 换算成秒/皮秒——这是 ADC 时钟与光通信最关心的单一指标。

二、仿真 ①：PLL 锁定过程瞬态仿真

对"PD(增益1) → PI 环路滤波器 → VCO(增益1) → ÷N"的二阶环做逐点数值仿真。VCO 自由振荡频率故意偏开 1%，观察闭环如何把它拉入锁定。默认 ζ=0.7：可看到轻微过冲后收敛；把 ζ 调小看振铃加剧，调大看过阻尼迟缓；调环路带宽看锁定快慢。
相位误差（rad，折回 ±π）——锁定后趋于恒定（积分支路把它压向 0）

四、小结与常见误区

要点回顾：① PLL=相位负反馈：PFD→环路滤波器→VCO→÷N；② PI 二阶环锁定后相位误差→0；③ ζ≈0.7、tlock≈4/(ζωn)；④ 带宽内噪声=参考×20lgN，带宽外=VCO，最优带宽≈两曲线交点；⑤ 整数 N 步进=fref，小数 N 靠 Σ-Δ 换小步进；⑥ L(f) 单位 dBc/Hz，裙边分段 1/f³→−20dB/dec→噪底；⑦ 积分相噪→RMS 抖动 σφ/2πf₀。
误区："PLL 把 VCO 的相位噪声消除了"。只是在环路带宽内用（倍频恶化的）参考噪声替换了 VCO 噪声；带宽外 VCO 原样保留。若参考质量差、N 又大，锁相反而让近端噪声变差——带宽选择就是在两个噪声源之间"择优"。
误区："比抖动就看某个频点的 dBc/Hz"。抖动是整条曲线的积分：不同器件积分区间不同（12 kHz~20 MHz 是光通信习惯，1~20 MHz 常见于时钟芯片），单点值既不唯一也不可比。读 datasheet 必须先看积分条件。
误区："小数 N 分频免费提高频率分辨率"。小数分频靠 Σ-Δ 抖动 N 值实现，瞬时相位误差注入环路 → 量化杂散。要压杂散就得更高过采样阶数与更讲究的环路滤波设计——"任意小步进"是有账单的。
