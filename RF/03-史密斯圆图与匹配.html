史密斯圆图与匹配

把复数阻抗装进一张圆图 —— 交互圆图读 Γ，L 网络综合器算元件值

一、理论要点

1. 先归一化

z = Z/Z₀　（50Ω 系统：Z 除以 50）
归一化让圆图适用于任何特征阻抗。50+j25Ω → z = 1+j0.5。圆图上一切坐标都是归一化阻抗 z = r + jx。

2. Γ 与 z 的一一映射

Γ = (z−1)/(z+1)　　z = (1+Γ)/(1−Γ)
无源阻抗 |Γ|≤1，所以所有阻抗都被压进单位圆内——史密斯圆图就是这张映射图。匹配点 z=1 → Γ=0（圆心）；短路 z=0 → Γ=−1（左端点）；开路 z=∞ → Γ=+1（右端点）。

3. 两族圆织成一张图

等电阻圆：圆心 (r/(1+r), 0)，半径 1/(1+r)，全部与右端点相切；
等电抗圆：圆心 (1, 1/x)，半径 |1/x|，上半圆感性、下半圆容性。
等 r 圆：心(r/(1+r),0) 径 1/(1+r)
任一阻抗点 = 某条等 r 圆与某条等 x 圆的交点。

4. 圆图怎么"读"

圆心=完美匹配；上半=感性（x>0），下半=容性；左端点短路、右端点开路。离圆心越近 |Γ| 越小、VSWR 越接近 1。以圆心为圆心的同心圆是等 VSWR 圆。

5. 沿线移动 = 转圈

传输线上每移动距离 l，Γ 相位转 −2βl：每半波长转一整圈。向源（发电机）方向移动 = 顺时针；向负载 = 逆时针。所以一段传输线本身就是"阻抗变换器"（λ/4 阻抗倒置：Zin=Z₀²/ZL）。

6. 串联看阻抗圆图，并联看导纳圆图

并联元件用导纳 y=1/z 更方便：导纳圆图就是阻抗圆图旋转 180°。并联电容 → 沿等电导圆向上（+jb 方向）；并联电感 → 向下。记忆：串联沿等 r 圆移动，并联沿等 g 圆移动。

7. 元件移动方向口诀

串联 L：等 r 圆向上；串联 C：向下；并联 L：等 g 圆向下（阻抗图上表现为向上）；并联 C：等 g 圆向上（阻抗图上向下）。加上"顺时针=向源"，任何匹配网络都能在圆图上一步步画出来。

8. L 网络：最简单的匹配

两个电抗元件（一串一并）即可把任意负载匹配到 50Ω：负载等效并联电阻大于 50Ω 用"并靠负载+串靠源"，反之用"串靠负载+并靠源"。代价是 Q 值被阻抗比强加：
Q = √(R高/R低 − 1)，带宽 ≈ f₀/Q
阻抗比越大 → Q 越高 → 带宽越窄。要低 Q/宽带得用 π 型、T 型或多节网络。

二、仿真 ①：交互史密斯圆图 —— 滑动 R/X 找 Γ

拖动 R、X 滑杆，看阻抗点（粉）在圆图上移动：上半平面感性、下半容性，虚部为零时点落在横轴上。黄色虚线是等 VSWR 圆，蓝线是 Γ 矢量。默认 100+j25Ω（z=2+j0.5）——一个明显失配的感性负载，与仿真②的算例一致。
负载点 z_L 匹配点 1+j0 等 VSWR 圆 Γ 矢量

三、仿真 ②：L 网络匹配综合器 —— 算出元件值

输入负载 ZL 与频率 f₀，自动综合一个两元件 L 网络（优先低通型：并联电容+串联电感）。右图轨迹：负载点 →（并联/串联第一个元件后）→ 中间点 →（第二个元件后）→ 圆心。读数给出 L/C 元件值、Q、带宽估计，并用复数运算数值验证 Zin=50+j0。
负载点 中间点（第一个元件后） 匹配点 50Ω
匹配前后的 |Γ|–频率示意：L 网络是窄带变换，Q 决定带宽

四、小结与常见误区

要点回顾：① 先归一化 z=Z/Z₀；② Γ=(z−1)/(z+1)，无源负载全在单位圆内；③ 等 r 圆与等 x 圆交点即阻抗；④ 上感下容、左短右开、心匹配；⑤ 沿线每 λ/2 转一圈，向源顺时针；⑥ 串联沿等 r 圆、并联沿等 g 圆；⑦ L 网络两元件完成匹配，Q=√(R高/R低−1) 不可选。
误区："匹配好了就处处 VSWR=1"。匹配网络只在设计频点 f₀ 完美。频率一偏，负载点在圆图上移动，网络元件的电抗也按 ±ωL、∓1/ωC 变化，两者不再抵消——VSWR 迅速变差。L 网络的带宽被 Q=√(R高/R低−1) 锁死，阻抗比大时是硬伤。
误区："圆图上永远沿等电阻圆走"。只有串联元件才沿等 r 圆移动；并联元件沿等电导圆（导纳圆图）移动。把串并搞混是画匹配轨迹最常见的错误——这也是为什么仿真②里中间点先"跳"到一条特殊位置：那一步是并联元件干的。
误区："Q 越高匹配越好"。高 Q 意味着：带宽窄、元件损耗被放大 Q 倍、电感电容上电压/电流摆幅大。L 网络 Q 由阻抗比强加，想要低 Q 只能改拓扑（π/T/多节）或接受宽带匹配网络的复杂度。
