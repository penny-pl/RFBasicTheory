SDR 基础（软件无线电）

I/Q 正交信号 · 星座图 · AM/FM 调制 · 混频与频谱搬移 · 瀑布图 —— 全部仿真在浏览器本地运行

一、SDR 是什么？

软件定义无线电（Software Defined Radio）：把滤波、混频、调制解调这些传统上用专用硬件完成的工作，尽量交给软件来做。硬件只负责"搬移到合适频率 + 数字化"，其余全由程序决定——同一台设备换个程序就能听 FM 广播、收 ADS-B 飞机信号、解码气象卫星。
天线接收电磁波
→
LNA低噪声放大
→
混频器RF 搬到中频/基带
→
ADC模数转换 I/Q
→
软件处理解调/解码/显示
常见设备：RTL-SDR（几十元的电视棒）、HackRF、USRP、ADALM-Pluto。

二、核心理论速览

1. 为什么用 I/Q 两路？

单路实信号采样无法区分 +f 和 −f（频谱镜像）。用相位差 90° 的两路本振分别混频，得到同相 I 与正交 Q：
x(t) = I(t) + j·Q(t)
复信号完整保留了幅度和相位信息，I/Q 是 SDR 的数据母语。

2. 采样率与带宽

复数采样时，可用带宽 = 采样率 fs（不是 fs/2！因为复信号无镜像）。RTL-SDR 常用 2.4 MS/s，即一次能观察 2.4 MHz 宽的频谱。

3. 调制：把信息"骑"在载波上

AM：信息改变载波幅度；FM：信息改变载波频率；PM：改变相位。数字调制则把比特映射为离散的幅度/相位状态（星座点），如 BPSK、QPSK、16QAM。

4. 星座图

把每个符号的 (I, Q) 画成平面上的点。噪声使点云扩散，扩散到相邻点的"地盘"就会误判。
16QAM 比 QPSK 点更密 → 速率×2，但更怕噪声

5. 混频与频谱搬移

两个信号相乘（混频），频率相加/相减：
cos(f₁)·cos(f₂) = ½[cos(f₁+f₂)+cos(f₁−f₂)]
用本振把 RF 信号"减"到中频或基带，ADC 才跟得上——这是所有接收机的核心操作。

6. 瀑布图（Waterfall）

把连续多帧 FFT 幅度谱按时间堆叠成图像，横轴频率、纵轴时间、颜色表示强度。SDR 软件的标志性界面，一眼看出"哪个频点什么时候有信号"。

三、SDR 关键技术理论

1. 超外差 vs 零中频

超外差：RF 先混到固定中频再数字化，镜像靠前端滤波器压制（传统收音机架构）。零中频（直接变频）：LO=载频，直接混到基带 I/Q，省掉中频和镜像滤波——大多数 SDR 芯片（如 AD9361、RTL2832U 后级）用它。代价：直流失调、IQ 不平衡需校准。

2. 带通采样（欠采样）

奈奎斯特定理只说采样率要超过带宽的 2 倍，没说要超过载频！窄带信号可以用远低于载频的速率采样，频谱会周期延拓到基带：
2fH/n ≤ fs ≤ 2fL/(n−1)
仿真⑤可亲手体验这种"故意的混叠"。

3. ADC 的关键指标

位数/ENOB：有效位数决定 SNR 上限；SFDR：无杂散动态范围，决定强弱信号能否同时看清；满量程：输入过载会削波产生大量谐波。SDR 常用 8~16 位。

4. 动态范围与 AGC

空中信号从 −110 dBm 到 −20 dBm 相差 90dB，远超 ADC 能力。AGC（自动增益控制）实时调节 LNA/可变增益放大器，把信号"安排"进 ADC 的最佳窗口——SDR 软件里的增益滑块就是它。

5. 抽取与插值（采样率变换）

ADC 采得飞快（如 28.8 MS/s），解调只需几十 kHz。先用抗混叠滤波器再每 M 点取 1 点（抽取），数据率大幅下降；反之插值用于发射。CIC、半带 FIR 是常用的多级滤波结构。

6. 常见设备与软件生态

RTL-SDR（¥30，收 0.5M~1.7G）、HackRF（收发，半双工）、ADALM-Pluto（教学）、USRP（科研）。软件：GNU Radio（图形化流图）、SDR#、GQRX。入门建议：RTL-SDR 收 FM 广播 → ADS-B 飞机信号 → 气象卫星云图。

四、仿真 ①：I/Q 星座图与噪声

随机发送数字符号并叠加高斯噪声，画出星座点云。调低 SNR 看点云扩散、临近判决边界——误码就是这么发生的。
横轴 I · 纵轴 Q · 灰色十字=理想星座点，彩色点=接收到的含噪符号

五、仿真 ②：AM / FM 调制解调

基带信号（音频，绿）调制到载波上。AM 看包络变化、FM 看疏密变化；右侧频谱可见 AM 的载波+上下边带、FM 的多边带结构（卡森带宽 BW≈2(Δf+fm)）。
基带信号 已调信号（载波 40 Hz）
已调信号频谱（载波两侧为边带）

六、仿真 ③：混频下变频（频谱搬移）

RF 信号与本振 LO 相乘后，频谱出现在 |fRF±fLO| 两处。用低通滤波器留下差频，就把高频信号搬到了基带。调 LO 频率观察频谱移动；fLO=fRF 时即为零中频（直接变频）。
原始 RF 频谱 混频产物（和频+差频） 低通滤波器通带

七、仿真 ④：实时瀑布图

模拟 SDR 软件的经典界面：滚动瀑布图。内置一个固定台站、一个跳频信号和一个缓慢漂移的信号，加底噪。点击画面可暂停/继续。
横轴：频率｜纵轴：时间（新的在顶部）｜颜色：信号强度

八、仿真 ⑤：带通采样 —— "故意的混叠"

一个 100~110 MHz 的窄带信号（如 FM 广播频段），直接用远低于载频的采样率采样。采样后频谱以 fs/2 为周期反复折叠延拓。调采样率，当折叠后的副本恰好完整落进 0~fs/2 且不与自身重叠时，就能从"低速"采样中恢复原信号——这是 SDR 省掉一级混频的常用技巧。
原始信号频带 100~110 MHz 及其延拓副本 0~fs/2 基带窗口（ADC 实际"看到"的）

九、数字下变频（DDC）与抽取滤波理论

1. DDC：SDR 接收机的第一道数字处理

ADC 以高采样率采下整个频段后，我们往往只关心其中一小段。数字下变频把目标频道"搬"到零频、滤掉其他频道、再降低数据率：
ADC 数据流如 100 MS/s
→
数字混频 ×NCO频道搬到 0 Hz
→
低通滤波 FIR/CIC只留目标频道
→
抽取 ÷M数据率降 M 倍
→ 基带 I/Q
输出一路低速率、高信噪比的复基带信号，交给后续解调软件。

2. NCO 数控振荡器

数字版本振：相位累加器每个时钟累加一个"频率字"，相位查正弦表输出 I/Q 两路本振：
φ[n+1] = (φ[n] + Δφ) mod 2π，Δφ = 2π·fnco/fs
改频率字即改频道——软件"调台"就是写这个寄存器。

3. 为什么抽取前必须先滤波

直接每 M 点取 1 点，等效采样率降为 fs/M，一切高于 fs/(2M) 的成分都会混叠回基带污染信号。所以顺序铁律是：
先低通滤波（截止 ≤ fs/(2M)），再抽取
这与 ADC 前加抗混叠滤波器是同一个道理，只是搬到了数字域。

4. CIC 滤波器：不用乘法器的抽取利器

级联积分梳状（CIC）滤波器只有加法器和延迟单元，零乘法，适合 FPGA 里跑几百 MS/s 的第一级大倍率抽取。代价：通带有下垂（droop），需要后级 FIR 补偿。

5. 半带 FIR 与多级抽取

半带滤波器近一半系数为零，专为 2 倍抽取优化。大抽取比（如 ÷64）通常级联实现：CIC÷16 → 半带÷2 → 半带÷2，逐级降压，远比单级 65 阶 FIR 直接 ÷64 省资源。

6. 抽取的隐藏福利：处理增益

抽取把噪声带宽收窄 M 倍，带内信噪比提升：
处理增益 = 10·lg(M) dB
÷16 抽取白赚 12 dB SNR——这就是为什么 SDR 喜欢"采得快、取得狠"。

十、仿真 ⑥：DDC + 抽取流水线

ADC 以 100 MS/s 采到两个信号：目标频道（30 MHz）与干扰（42 MHz）。流水线：①混频 NCO 把目标搬到 0 Hz → ②FIR 低通滤掉干扰 → ③抽取降数据率。三幅图逐级观察频谱变化。试试把抽取率开大、滤波器截止调宽——违反"先滤波再抽取"时干扰混叠回基带。
① ADC 输入频谱（0~50 MHz 实信号）：目标 30 MHz + 干扰 42 MHz
② 混频 + FIR 低通后（复基带，±50 MHz）：目标在 0 Hz，干扰被滤除
③ 抽取后输出（±50/M MHz）：数据率 ÷M，信号保留
